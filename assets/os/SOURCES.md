# Operating system logos

These come from Wikimedia Commons, which renders each SVG as a PNG 120 pixels wide
(`https://commons.wikimedia.org/wiki/Special:FilePath/<file>?width=120`); they aren't changed
otherwise. The logo each system's Wikipedia page uses, its symbol without the name when there is one.
`ui/logos.slint` embeds them, and Slingshot shows them on the matching boot
entries.

These logos are trademarks of their owners. Slingshot uses them only to
show which system an entry starts, and they don't imply any endorsement.
