# Contributing to Slingshot

## Reporting a bug

Most bugs depend on the machine, so say which one it is (maker and model), and
which file system drivers Slingshot loads, if any.

Attach the log: on the System screen, F12 saves it as `slingshot.log` next to
`slingshot.efi`, with the machine's details. For something you see on the
screen, a photo helps too.
